# 📰 News Analysis using Machine Learning

 Summary

The News Analysis project is a machine learning application that identifies whether a news article is **Fake** or **Real** using Natural Language Processing (NLP) techniques. The system preprocesses news text, extracts important features using TF-IDF vectorization, and applies machine learning algorithms for accurate classification.

The project includes data cleaning, text preprocessing, feature extraction, model training, evaluation, and prediction. Models such as Logistic Regression, Decision Tree, and Random Forest are used to improve classification performance.

This project helps reduce the spread of misinformation by providing a simple and effective fake news detection system. Built using Python and libraries like Pandas, Scikit-learn, NLTK, and Matplotlib, it offers a complete workflow from dataset processing to real-time prediction.
